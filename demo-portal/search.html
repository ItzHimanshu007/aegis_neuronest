Search vs commit

← back

Pressing Enter in a form submits it, so Aegis treats Enter as a commit (L5) by default. A search box is the one exception — but only when the whole form has earned it. These four cases are what extension/authority has to separate.

1. Plain search form — Enter should be L2

2. Search landmark, no form — Enter should be L2

3. Look-alike form that is not a search — Enter must stay L5

4. Search box sharing a form with a sensitive field — Enter must stay L5

5. Search form posting cross-origin — Enter must stay L5
